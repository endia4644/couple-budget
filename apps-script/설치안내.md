# 우리 가계부 (정윤 · 민서) 설치 안내

휴대폰에서 바로 열어 쓰는 둘만의 가계부입니다. 정산까지 됩니다.
기록은 정윤 구글 드라이브의 **구글 시트 한 장**에 쌓이고, 둘이 같은 링크를 엽니다.
민서는 구글 계정이나 Claude가 없어도 됩니다.

- 비용: 무료 (구글 Apps Script)
- 아이폰 · 안드로이드 둘 다 됨 (앱스토어 설치 아님, **홈 화면 아이콘**으로 씀)

---

## 1. 시트 만들기 (정윤 PC에서, 10분)

1. [sheets.new](https://sheets.new) 로 새 구글 시트를 만들고 이름을 `우리 가계부`로 바꿉니다.
2. 메뉴 **확장 프로그램 → Apps Script** 를 누릅니다.
3. 왼쪽 `Code.gs` 안의 내용을 다 지우고, 이 폴더의 **`Code.gs` 내용을 통째로 붙여넣습니다.**
4. 맨 위 `PIN: '0000'` 의 `0000`을 **둘만 아는 숫자**로 바꿉니다.
5. 왼쪽 **파일 옆 `+` → HTML** 을 눌러 이름을 `Index` 로 만들고 (`.html`은 자동으로 붙음),
   이 폴더의 **`Index.html` 내용을 통째로 붙여넣습니다.**
6. 저장(💾) 후, 위쪽 함수 목록에서 **`setup`** 을 골라 **실행**합니다.
   - "권한 검토" 창이 뜨면 → 내 계정 선택 → **고급 → (안전하지 않음)으로 이동 → 허용**
     (내가 만든 스크립트라 구글이 검증을 안 했다는 뜻입니다)
   - 시트에 `기록` 탭이 생기면 성공입니다.

## 2. 웹앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴 → **웹 앱**
3. 설정:
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**  ← 민서가 로그인 없이 쓰려면 이것
4. **배포** → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
5. 이 URL을 카톡으로 민서에게 보냅니다. (URL + PIN을 아는 사람만 쓸 수 있습니다)

## 3. 휴대폰 홈 화면에 아이콘 만들기 (둘 다)

- **아이폰**: Safari로 URL 열기 → 아래 공유 버튼(□↑) → **홈 화면에 추가**
- **안드로이드**: Chrome으로 URL 열기 → 오른쪽 위 ⋮ → **홈 화면에 추가**

처음 열면 PIN과 "나는 정윤 / 나는 민서"를 한 번 고릅니다. 그다음부터는 바로 입력 화면이 뜹니다.

## 쓰는 법

| 나누기 | 언제 | 정산 |
|---|---|---|
| **반반** | 둘이 같이 쓴 돈 (밥, 장보기) | 상대가 **절반**을 줘야 함 |
| **내 것** | 혼자 쓴 돈 | 기록만, 정산 없음 |
| **상대 것** | 상대 걸 내가 대신 산 돈 | 상대가 **전부** 줘야 함 |

**화면 순서 (위 → 아래)**

1. **날짜** — 맨 위에 `11월 13일 금요일 · 오늘`. ‹ › 로 하루씩 넘기고, **📅 날짜 고르기**로 달력에서 아무 날이나 고른다.
   지난 날짜로 가 있으면 **오늘로** 버튼이 생긴다. (위로 고정돼 있어서 내려도 날짜가 보인다)
2. **그날 쓴 돈** — 합계, 항목 4칸(식비 · 간식 · 쇼핑 · 기타 부대비용), 누가 얼마 냈는지, 그날 내역.
   내역 왼쪽 색 줄 = 항목, 이름표 = 낸 사람. 잘못 넣은 건 **×** 로 지운다.
3. **지출 추가** — 지금 보고 있는 날짜로 들어간다. 금액 → 항목 → 저장. (항목은 꼭 골라야 저장됨)
4. **정산** — "민서 → 정윤 16,000원". 송금했으면 **정산했어요** → 보낸 금액 입력 (일부만 보내도 됨).
5. **○월 전체** — ‹ › 로 **지난달도 넘겨 볼 수 있다.** 합계, 사람별 실제 부담, 항목별 막대, 기록 있는 날짜 목록(건수·합계).
   날짜를 누르면 그날로 올라간다. 정산 금액은 달과 상관없이 지금까지 전체 기준.

## 고치고 싶을 때

- **항목**(식비·간식…)이나 **이름**: `Code.gs` 맨 위 `CFG` 를 고치고 저장
  → **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** (URL은 그대로 유지됨)
- **PIN 변경**: 같은 방법. 바꾸면 휴대폰에서 PIN을 한 번 다시 넣게 됩니다.
- 시트를 민서와 **보기 권한으로 공유**하면 민서도 원본 기록을 볼 수 있습니다 (선택).

## 저장했는데 안 보일 때

1. **저장 버튼 아래 빨간 상자**가 떴는지 본다. 거기 적힌 대로 하면 된다.
   - "Code.gs가 예전 버전이에요" → Code.gs를 새로 붙여넣고 아래 *새 버전 배포*.
   - "저장/불러오기 실패: …" → 그 문구를 캡처해서 Claude에게 보낸다.
2. **항목 줄이 빨개졌다**면 항목을 안 고른 것. 하나 고르고 다시 저장.
3. **맨 위 날짜**가 오늘이 맞는지 본다. 지난 날짜를 보고 있으면 그날로 들어간다.
4. 구글 시트 `기록` 탭에 줄이 생겼는지 본다. **줄은 있는데 화면에 안 보이면** 예전 Code.gs다 → 새로 붙여넣기.
5. 코드를 바꿨으면 반드시 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**. 저장만 하면 휴대폰엔 예전 화면이 뜬다.

## 알아둘 점

- 링크로 열면 화면 맨 위에 "Google Apps Script 사용자가 만든 애플리케이션입니다"라는
  회색 줄이 뜹니다. 구글이 붙이는 것이라 끌 수 없습니다.
- 인터넷이 없으면 저장되지 않습니다 (저장 버튼 누른 뒤 "저장했어요"가 떠야 저장된 것).
- 기록 시트의 날짜는 글자 그대로(`2026-11-13`) 저장됩니다. 시트에서 직접 고칠 때도 이 형식으로 쓰세요.
